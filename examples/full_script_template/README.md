# Introduction

This is a full script simulation for acoustics using Quanscient Allsolve public API,
where you provide the mesh yourself.

# Prerequisites

Follow [Installation](../README.md#installation) and [Running](../README.md#running)
in the parent example README to set up Python, install the Allsolve SDK,
and configure credentials.

This example also requires gmsh:

```
(venv) $ pip install -r requirements.txt
```

# Running

From the `examples/` directory:

```
(venv) $ python full_script_template/main.py
```
